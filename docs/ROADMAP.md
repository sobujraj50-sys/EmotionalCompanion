# Roadmap

## Phase 01: code complete (v1.0.0, 2026-11-25)
A Foundation → B Design & navigation → C Secure API config → D Live audio prototype → E Emotional Voice Studio → F Testing & APK. Waiting for on-device verification with a real key.

## Carry-overs from Phase 01
- Stable release signing (repository secrets), after the user approves
- R8 minification + keep rules, with a device test
- Gemini TTS (`gemini-3.1-flash-tts-preview`) for auditions, if Live doesn't read lines verbatim
- Ephemeral tokens / backend before any distribution beyond a personal phone

## Later phases (interfaces prepared in Phase 01, not implemented)
- Long-term memory, user-controlled and viewable/deletable
- Mood journal
- Proactive conversation and daily routines
- Time-zone awareness and reunion countdown
- Love-letter generator: helps the user write *to his wife*
- Relationship Connect: features that bring the couple closer, such as sharing notes with his wife
- Real voice memories: playing back recordings the user owns, clearly labeled, never used to clone a voice
- Local wake word, microphone foreground service, always-on standby (each needs its own privacy review)
- Backend or ephemeral-token auth before any distribution beyond a personal APK
